# 구현 및 검증 기록

작성일: 2026-10-22 (한국 시각). 소스 작성과 실제 배포 검증을 구분합니다.

## 구현된 파일

- PHASE 1: 패키지·Vite·TypeScript·Tailwind·Wrangler 설정
- PHASE 2: D1 마이그레이션, 공개 API, 인증된 관리자 API
- PHASE 3: 서명 방문자 쿠키, HMAC 파생 식별자, 원자적 표 저장, 중복 제약, 재시도·내 표 조회
- PHASE 4: 관리자 세션·CSRF·비밀번호 해시·속도 제한, 참가자·경기·집계·기록·CSV
- PHASE 5: 한국어 모바일 투표, 관리자 운영, 16:9 프로젝터, 결과 그래프·동점, QR 생성·인쇄
- PHASE 6: 보안·API·DB 테스트, 실제 workerd 호환 테스트 구성, k6 A~F 스크립트
- PHASE 7: 한국어 설치·배포·API·운영·장애·비용 안내

마지막 SQLite 700표 실행의 SQL 호출 시간: p95 약 430.53ms, 최대 약 950.51ms. 전체 DB 테스트 4개는 약 1.41초. **이는 로컬 SQLite 연결·락 경합 포함 수치이며 HTTP 응답 시간이나 Cloudflare 성능이 아닙니다.** 반복 실행 결과는 스케줄링에 따라 달라집니다. 700명의 실제 동시 HTTP 접속을 측정한 것으로 해석하지 마세요.

API 테스트는 실제 `worker/index.ts`를 호출하되 D1 인터페이스를 Python SQLite 어댑터로 연결합니다. 준비된 SQL 문장·트랜잭션·트리거·서버 응답·쿠키·접근 제어를 검증합니다. Cloudflare의 workerd 런타임·분산 네트워크·D1 서비스의 제한을 재현하지는 않습니다.

추가 실행:

- 환경에 이미 있던 Babel 파서로 `src/main.tsx`, `src/api.ts`, Worker 두 파일, Vite 설정의 TypeScript/JSX 구문 파싱 통과
- Node 구문 검사로 Worker·비밀키 도구·k6 스크립트·workerd 테스트 통과
- Python으로 실제 마이그레이션 전체 실행 및 DB 제약 테스트 통과

구문 파싱은 타입 검사나 Vite 빌드를 대체하지 않습니다.

## 시도했으나 실행하지 못한 검증

1. npm 저장소 연결: 환경 프록시 `proxy:8080` 연결 실패.
2. `npm install --offline --ignore-scripts --no-audit --no-fund`: 캐시가 없어 ENOTCACHED.
3. `npm run build`: 의존성이 없어서 `tsc: not found`로 중단. **전체 타입 검사·프로덕션 번들 생성 미검증.**
4. Wrangler·Miniflare 실행: 의존성 미설치, 계정·DB·Secrets 미설정으로 미실행.
5. 브라우저·실기기: 실행 가능한 프런트 번들이 없어 미실행. 시각적 품질·반응형·QR 스캔·쿠키 브라우저 호환은 현장 확인 필요.
6. k6: 도구 미설치 및 시험 서버 미구동으로 A~F 실제 700 VU 미실행.
7. 실제 배포: Cloudflare 자격 증명·운영 DB ID·Secrets가 제공/설정되지 않아 미실행.
8. 최신 공식 문서/버전 조회: 외부 연결 실패로 확인하지 못함. 버전 범위와 공개적으로 지원되는 구성에 맞췄으나 설치 시점의 안정 버전으로 재확인 필요.

네트워크 권한 확장 시도가 대기하다 중단된 뒤에는 같은 권한 요청을 반복하지 않고 오프라인 구현·검증을 진행했습니다.

## 운영 전에 남은 작업

```bash
npm install
npm test
npm run build
npm run test:workerd
```

`test:workerd`는 Wrangler로 생성한 실제 Worker 번들을 Miniflare/workerd와 D1 바인딩으로 검사합니다. 사용 중인 Wrangler에서 유효한 D1 설정이 필요할 수 있습니다. 실제 Cloudflare 스테이징 검증을 대체하지 않습니다.

README에 따라 Cloudflare 로그인 → 운영/스테이징 D1 분리 → 마이그레이션 → Secrets → 배포를 수행합니다. 이후 스테이징 k6 A~F와 휴대폰 리허설을 마쳐야 행사에 사용할 수 있습니다. 빌드/실환경 검증이 끝나지 않은 현 상태를 ‘행사 운영 검증 완료’로 판단하면 안 됩니다.
